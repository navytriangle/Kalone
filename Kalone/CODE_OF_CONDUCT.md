# 행동 강령

이 프로젝트는 서로를 존중하는 공개 협업을 지향합니다.

- 사람이 아니라 **아이디어와 코드**에 대해 이야기합니다.
- 초보자의 질문을 환영하고, 모르는 것을 모른다고 말하기 쉬운 분위기를 지킵니다.
- 비판은 구체적이고 건설적으로, 가능하면 대안과 함께 전합니다.
- 괴롭힘, 차별, 인신공격, 개인정보 노출은 허용하지 않습니다.
