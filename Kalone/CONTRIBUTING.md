# 기여 가이드

Kalone에 관심 가져 주셔서 감사합니다. 작은 실험 하나, 오타 수정 하나도 환영합니다.

## 시작하기

```bash
git clone https://github.com/navytriange/Kalone.git && cd Kalone
pip install -e ".[dev]"
pytest            # 전부 통과해야 PR을 받을 수 있습니다 (CPU에서 1~2분)
```

## 기여 방법

1. 이슈를 먼저 열거나 [ROADMAP](ROADMAP.md)에서 하나를 고릅니다. 이미 누가 하고 있는지 댓글로 확인해 주세요.
2. 브랜치를 만들어 작업합니다. (`feat/...`, `fix/...`, `docs/...`)
3. **변경에 맞는 테스트를 추가**합니다. 새 과제라면 `test_gold_actions_reproduce_target` 이 자동으로 검사합니다.
4. PR 템플릿의 체크리스트를 채워 PR을 엽니다. 한 PR은 한 가지 주제만 담아 주세요.

## 결과 보고 규칙

"정확도가 올랐다"는 주장은 **재현 가능해야** 합니다. 개선 PR/이슈에는 아래를 꼭 적어 주세요.

- 실행 명령 전체 (`python -m kalone.train --steps ... --seed ...`)
- **시드**, 학습 스텝/배치 크기, 모델 크기
- **평가 문항 수와 시드** (기본: 300문항, 시드 1234), 과제별 정확도
- 기준선(현재 main)과의 비교. 가능하면 시드 2개 이상 평균
- 평가 분포가 학습과 **같은지 다른지** (더 긴 입력, 처음 보는 형식 등)

과제를 바꾸면 이전 숫자와 직접 비교할 수 없으니, 그 경우 기준선도 같은 과제로 다시 돌려 주세요.

## 코드 스타일

- Python 3.9+, 타입 힌트는 있으면 좋고 필수는 아닙니다.
- 모델 코드는 읽기 쉬운 쪽을 우선합니다. 연구용 프로토타입이라 최적화보다 명료함이 중요합니다.
- 체크포인트(`.pt`)는 용량이 작을 때(수 MB)만 커밋하고, 큰 것은 Release 에 올려 주세요.

## 안전·윤리 관련

복사 기능은 저작권, 출처 표기, 프롬프트 인젝션과 맞닿아 있습니다. 외부 저작물을 대량으로 복사하는 데모나 데이터는 PR로 받지 않습니다. 복사 범위 제한, 출처 추적처럼 **안전장치를 더하는 기여는 특히 환영**합니다.
